# Forms

Forms define the information shown or collected during a Human Task. They turn process variables into a user-facing interaction with labels, field types, validation, choices, and document controls.

A form has a stable key and can be versioned independently. A Human Task references that key, maps process data into the form, and maps submitted values back into the process.

Design forms around the decision the user must make. Group related fields, use clear labels, mark only essential fields as required, and make reference information read-only. Avoid exposing technical IDs or process data that the user does not need.

File upload, download, and PDF viewing controls connect forms with document handling. Access and task assignment still determine who may see and complete the work.

See [Forms](../guides/forms.md) for deployment and retrieval, and [Form modeler](../platform/modeler.md#form-modeler) for available controls.
